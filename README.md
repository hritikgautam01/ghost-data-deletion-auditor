## 1. Project Overview

**Ghost Data Still Exists** is an AI-powered compliance and forensics agent designed to audit personal data deletion requests. 

A standard data deletion workflow may claim a request is **"Complete,"** yet personal data often persists in read replicas, logs, search indexes, analytics extracts, archives, support tickets, and backups. Active synchronization pipelines and restore jobs can also recreate deleted data, leading to catastrophic compliance and financial liabilities (such as Northstar Shop's $2.4 million ghost data incident).

This agent:
1. Determines whether a customer request authorizes personal data deletion (`COMPLETE` / `INCOMPLETE`) or represents a non-deletion action (`NOT_APPLICABLE`).
2. Reconstructs historical customer identities (linking former emails, phone numbers, and hashes via grounded audit logs).
3. Investigates multi-modal evidence across databases, search indexes, caches, support tickets, and backups.
4. Identifies active data flows and unblocked backup restores that pose resurrection risks.
5. Applies the organization's 15 explicit deletion rules (including account tombstone and legal retention rules).
6. Generates a strictly ordered verification or remediation plan in JSON (`steps_json`).
7. Outputs an RFC 4180 compliant `output.csv` with exactly 518 evaluation rows.

## 3. Quick Start & Execution

### 3.1 Setup Environment

Ensure Python 3.10+ is available:

```bash
# Verify Python version
python --version
```

### 3.2 Running the Solution

The solution entry point is runnable directly from the repository root:

```bash
# Process all 518 evaluation requests and generate output.csv
python code/main.py --all --output-file output.csv

# Run an individual case
python code/main.py --case case_33

# Run sample evaluation against ground truth
python code/evaluation/main.py --run-sample

# Run independent output validation
python scripts/validate_output.py output.csv
```
